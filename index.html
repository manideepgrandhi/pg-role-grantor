      Permission coverage & boundaries All object GRANT privileges for supported majors

      Database, schema, table, view, foreign table, column, sequence, function, procedure, routine, type, domain, language, foreign data wrapper, foreign server, tablespace, large object, and configuration parameter privileges. MAINTAIN requires 17. Parameter privileges require 15 or later.

      Default privileges cover future tables, sequences, routines, types, and schemas by creator. Schema defaults are global within a database. Predefined PostgreSQL roles are separate from scoped access profiles.

      Ownership, ALTER/DROP authority, elevated role attributes, RLS policies, passwords, and AWS IAM are not GRANT privileges and are not configured here. Aurora host-level operations may be unavailable even when SQL syntax exists. FDW setup generates extension, server, explicit user mappings, optional import or manual foreign tables, and local grants. Passwords are placeholders only. No database connection, account sign-in, execution, analytics, or form-data storage.
